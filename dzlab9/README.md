# Домашнее задание к работе 9

## Условие задачи (Вариант 11)

Написать программу, выводящую на экран заданную в ДЗ к лабораторной работе № 6 фигуру (закрашенную область из варианта 11), нарисованную с помощью заданного с клавиатуры символа.

Фигура расположена справа от оси Oy (x ≥ 0) и состоит из двух частей:
- при y ≥ 0 — часть эллипса x²/16 + y²/9 ≤ 1;
- при y < 0 — часть круга x² + y² ≤ 16.

Предусмотреть возможность изменения размеров фигуры путем задания пользователем размера `k` (количество символов в единице длины).

Обеспечить повторение выполнения программы в цикле с постусловием `do-while` до тех пор, пока пользователь не захочет ее завершить.

## 1. Алгоритм и блок-схема

### Алгоритм

1. Настроить русскую локализацию для корректного вывода сообщений.
2. Начать цикл с постусловием `do-while`.
3. Запросить у пользователя и считать символ `ch`, из которого будет строиться фигура.
4. Запросить и считать размер фигуры `k` (количество символов в единице длины).
5. Проверить корректность размера: `k` должно быть больше нуля.
6. Если размер некорректен, вывести сообщение об ошибке.
7. Если размер корректен, построить фигуру по строкам:
   - для каждой строки `r` от 0 до `14k` вычислить координату `y = 3 - r / (2k)`;
   - для каждого столбца `c` от 0 до `4k` вычислить координату `x = c / k`;
   - если точка `(x, y)` принадлежит области (`x ≥ 0` и выполняется одно из условий: `y ≥ 0` и `x²/16 + y²/9 ≤ 1`, либо `y < 0` и `x² + y² ≤ 16`), вывести символ `ch`, иначе вывести пробел;
   - после каждой строки перейти на новую строку.
8. Запросить признак продолжения `cont` (любое число — продолжить, 0 — завершить).
9. Если `cont` не равно 0, повторить цикл с пункта 3; иначе завершить программу.

Масштаб: по горизонтали одна единица длины занимает `k` символов, по вертикали — `2k` строк, так как символ в консоли примерно вдвое выше своей ширины. Поэтому фигура выглядит пропорционально.
