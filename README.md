# Домашнее задание к работе 9

## Условие задачи (Задача А, Вариант 11)

Написать программу, выводящую на экран равнобедренную трапецию, нарисованную с помощью заданного с клавиатуры символа. Фигура задаётся только контуром. Параметры фигуры: верхнее основание `b`, высота `h`, нижнее основание `c`. Размеры задаются пользователем в символах.

Повтор выполнения программы организован в цикле с постусловием `do-while` до тех пор, пока пользователь не завершит работу.

* * *

## 1. Алгоритм и блок-схема

### Алгоритм

1. Установить локаль для корректного вывода русского текста.
2. Начать цикл с постусловием `do-while`.
3. Запросить и считать символ `ch`, которым будет нарисована фигура.
4. Запросить и считать верхнее основание `b`, высоту `h` и нижнее основание `c`.
5. Проверить корректность размеров: `b > 0`, `h >= 2`, `c >= b`.
6. Если размеры некорректны, вывести сообщение об ошибке.
7. Если размеры корректны, вызвать функцию `draw_trapezoid(ch, b, h, c)`, которая рисует контур трапеции по строкам:
   - сдвиг верхнего основания `a = (c - b) / 2`;
   - для каждой строки `r` от 0 до `h - 1` вычисляются левая граница `xl` и правая граница `xr`;
   - в строках `r = 0` и `r = h - 1` выводятся все символы между `xl` и `xr`, в остальных строках выводятся только символы на границах `xl` и `xr`;
   - остальные позиции выводятся пробелами.
8. Запросить признак продолжения `ans` (1 — продолжить, 0 — завершить).
9. Если `ans` не равно 0, вернуться к пункту 3; иначе завершить программу.

## 3. Результаты работы программы

```

Введите верхнее основание b: 3
Введите высоту h (не меньше 2): 3
Введите нижнее основание c (не меньше b): 5
 ***
 *  *
*****
Продолжить? (Да - 1, нет - 0): 1
```

####
